
# F4992-ESP32-S3 Smart Turntable Addons

## Purpose

There are a few configurable Add-Ons for the turntable - things that were not present in the original design in the 80s but can be turned to the user's advantages.
These are configurable. Keeping them OFF keeps the software behaving like it did in the 80s.


## GUI

Some of the options are purely within the interface itself - adding repeat (a P-L55 feature) to turntables that didn't have it (like the P-L35 or P-L45) or a soft speed inverter to behave just like the hardware one, but via software.
Other options are more advanced within how the turntable will function, or may even require specific hardware.

By default, the features are not even visible in the web configuration utility.
To make them visible, turn on the Advanced settings and H/W tab in the addons tab.
When the tabs are not visible, the options choices remains. It is suggested to keep the web interface as lean as possible by disabling most tabs for normal usage.
